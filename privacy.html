Privacy Policy — clipper

Last updated: November 22, 2026

clipper is a personal tool used only by its owner to publish short video clips to the owner's own accounts on YouTube, Instagram and TikTok through their official APIs. It has no other users.

Data accessed

  • YouTube (YouTube API Services): an OAuth token with the youtube.upload scope, used only to upload videos that the owner has reviewed and approved, and to read the ID and URL of each uploaded video.
  • Instagram and TikTok: access tokens for the owner's own account, used only to publish the owner's approved videos and read their URL.

clipper does not collect, store or process data from any other person or account.

Storage and sharing

Tokens are stored on the owner's private server, which is only reachable through a private network, and are never shared with third parties or used for advertising.

Use of YouTube API Services

clipper uses YouTube API Services. By using clipper you agree to be bound by the YouTube Terms of Service, and your information is also subject to the Google Privacy Policy (https://policies.google.com/privacy).

clipper's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Data obtained through YouTube API Services is not shared with third parties.

Retention and revocation

Tokens are kept only while the owner uses clipper. Access can be revoked at any time at https://myaccount.google.com/permissions (Google/YouTube) and in the security settings of each platform. On revocation, stored tokens are deleted.

Data deletion

The only YouTube API data stored are the IDs and URLs of the videos clipper uploads to the owner's channel. The owner can delete them, together with the stored tokens, at any time. If access is revoked at Google security settings, the owner deletes the stored token and these records within 7 days, and never keeps them for more than 30 days without an active authorization. Deletion requests can be sent to the contact address below.

Third-party terms

clipper uses YouTube API Services. By using it, the owner agrees to the YouTube Terms of Service; see also the Google Privacy Policy.
